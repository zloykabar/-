Общая информация

Базовые понятия, которые нужны для понимания любой сети — от домашней до корпоративной.

ПонятиеОпределениеПример
IP-адрес Уникальный числовой адрес устройства в сети. Бывает IPv4 (32 бита) и IPv6 (128 бит). 192.168.1.10
Маска подсети Определяет, какая часть IP-адреса относится к сети, а какая — к хосту. Часто записывается как префикс /24. 255.255.255.0 = /24
Шлюз (Default Gateway) IP-адрес устройства (обычно роутера), через которое компьютер выходит в другие сети, включая интернет. 192.168.1.1
DNS Domain Name System — система, преобразующая понятные имена в IP-адреса. google.com → 142.250.74.14

Как посмотреть свои параметры

Windows: ipconfig /all
macOS: ifconfig или ipconfig getifaddr en0
Linux: ip addr или ifconfig -a

Диапазоны частных (локальных) адресов

  • 10.0.0.0/8 — крупные корпоративные сети
  • 172.16.0.0/12 — средние сети
  • 192.168.0.0/16 — домашние и офисные сети

Диагностика сети

Основные команды для проверки соединения и поиска проблем. Приведены для Windows, macOS и Linux.

Ping — проверка доступности узла

Windows: ping 8.8.8.8 (по умолчанию 4 пакета)
macOS / Linux: ping 8.8.8.8 (бесконечно, остановить Ctrl+C)

Показывает, отвечает ли узел, и время отклика (RTT).

Traceroute / Tracert — маршрут до узла

Windows: tracert google.com
macOS / Linux: traceroute google.com

Показывает все промежуточные маршрутизаторы (хопы) на пути к цели.

NSLookup / Dig — проверка DNS

Windows / macOS / Linux: nslookup google.com
macOS / Linux (расширенно): dig google.com

Проверяет, правильно ли имя домена преобразуется в IP.

Netstat / SS — соединения и порты

Windows: netstat -an
macOS / Linux: netstat -tuln или ss -tuln

Показывает открытые порты и активные подключения.

Проверка конкретного порта

Windows (PowerShell): Test-NetConnection google.com -Port 443
macOS / Linux: nc -zv google.com 443

Сброс сетевых настроек (если ничего не помогает)

Windows: ipconfig /flushdns, ipconfig /release + ipconfig /renew
macOS: sudo dscacheutil -flushcache
Linux: sudo systemctl restart NetworkManager
Совет: если ping 8.8.8.8 работает, а сайты не открываются — проблема почти наверняка в DNS.

HTTP vs HTTPS

Определения

HTTP (HyperText Transfer Protocol) — протокол передачи гипертекста. Передаёт данные между браузером и сервером в открытом виде.

HTTPS (HTTP Secure) — тот же HTTP, но работающий поверх шифрования TLS/SSL. Данные передаются зашифрованными.

Ключевые отличия

Параметр HTTP HTTPS
Порт по умолчанию80443
ШифрованиеНет, открытый текстДа, TLS/SSL
Защита от перехватаУязвим (MITM, сниффинг)Защищён
Аутентификация сервераНетДа, через сертификат
Целостность данныхНе гарантируетсяКонтролируется
СкоростьЧуть быстрее (нет шифрования)Незначительно медленнее
Современный статусУстаревшийСтандарт де-факто

Что даёт HTTPS

  • Шифрование — пароли, карты, переписка не видны провайдеру и злоумышленнику.
  • Аутентификацию — сертификат подтверждает, что вы на настоящем сайте, а не на фишинговой копии.
  • Целостность — данные нельзя незаметно подменить по пути.

Проверка сертификата в терминале

Windows / macOS / Linux: curl -v https://example.com
Открыть сертификат: openssl s_client -connect example.com:443 -servername example.com
HTTPS — это не «отдельный протокол», а HTTP поверх TLS. Порт 443 и «замочек» в браузере — просто внешние признаки.

Серверы

Что такое сервер

Сервер — это компьютер (или программа), который предоставляет ресурсы, данные или сервисы другим устройствам — клиентам — по сети. Клиент отправляет запрос, сервер его обрабатывает и возвращает ответ.

Типы серверов: веб-сервер (Apache, Nginx), файловый (SMB, FTP), почтовый, базы данных (MySQL, PostgreSQL), DNS, игровой и т.д.

Основные порты серверных сервисов

СервисПортНазначение
HTTP80Веб без шифрования
HTTPS443Веб с шифрованием
SSH22Удалённое управление Linux
RDP3389Удалённый рабочий стол Windows
MySQL3306База данных MySQL
PostgreSQL5432База данных PostgreSQL
DNS53Разрешение имён
SMB445Сетевые папки Windows

Как подключиться к серверу

Linux / macOS: ssh user@server_ip
Windows (PowerShell 10+): ssh user@server_ip
Windows (GUI): PuTTY, MobaXterm или WinSCP

Для Windows-серверов — RDP-клиент mstsc (встроен в Windows) или Microsoft Remote Desktop на macOS.

Как проверить доступность сервера и порта

Пинг: ping server_ip
Порт (macOS / Linux): nc -zv server_ip 443
Порт (Windows PowerShell): Test-NetConnection server_ip -Port 443
HTTP-ответ: curl -I https://server_ip

Просмотр открытых портов на самом сервере

Linux: ss -tuln или netstat -tuln
Windows: netstat -an

Базовые принципы работы с сервером

  • Никогда не работайте под root постоянно — используйте sudo и отдельного пользователя.
  • SSH-ключи безопаснее паролей: ssh-keygen → ssh-copy-id user@server.
  • Обновляйте систему: sudo apt update && sudo apt upgrade (Debian/Ubuntu) или sudo dnf upgrade (RHEL/Fedora).
  • Проверяйте логи: journalctl -xe, tail -f /var/log/syslog.
  • Для Windows — Event Viewer и Get-EventLog в PowerShell.

Маршрутизатор

Что такое маршрутизатор

Маршрутизатор (router) — устройство, которое соединяет разные сети и направляет пакеты между ними на основе таблицы маршрутизации. Домашний роутер — это маршрутизатор + коммутатор + точка доступа Wi-Fi в одном корпусе.

Основные команды (на примере Cisco IOS)

ЗадачаКоманда
Вход в привилегированный режимenable
Режим конфигурацииconfigure terminal
Просмотр таблицы маршрутизацииshow ip route
Добавить статический маршрутip route <сеть> <маска> <шлюз>
Сохранить конфигурациюcopy running-config startup-config
Просмотр интерфейсовshow ip interface brief
Список VLANshow vlan brief

Просмотр портов и интерфейсов

Cisco: show interfaces status, show ip interface brief
MikroTik: /interface print, /ip address print
Linux-роутер: ip link show, ip addr, ss -tuln
Windows-роутер (RRAS): Get-NetAdapter, Get-NetIPAddress, netstat -an

Настройка VLAN (пример на Cisco)

! Создаём VLAN 10
vlan 10
 name Office
 exit

! Назначаем порт в VLAN
interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
 exit

! Проверка
show vlan brief
show interfaces status

Транковый порт (передача нескольких VLAN)

interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30
 exit

MikroTik: VLAN через bridge

/interface bridge vlan
add bridge=bridge1 tagged=ether1 untagged=ether2 vlan-ids=10

/interface bridge port
set [find interface=ether2] pvid=10

Linux: VLAN через iproute2

sudo ip link add link eth0 name eth0.10 type vlan id 10
sudo ip addr add 192.168.10.1/24 dev eth0.10
sudo ip link set eth0.10 up
Важно: команды VLAN сильно зависят от производителя. Указанные примеры — для Cisco IOS (учебный стандарт), MikroTik RouterOS и Linux-роутеров. На домашних роутерах (TP-Link, ASUS, Keenetic) VLAN обычно настраивается через веб-интерфейс, а не через CLI.
