Общая информация

Базовые понятия, которые нужны для понимания любой сети — от домашней до корпоративной.

ПонятиеОпределениеПример
IP-адрес Уникальный числовой адрес устройства в сети. Бывает IPv4 (32 бита) и IPv6 (128 бит). 192.168.1.10
Маска подсети Определяет, какая часть IP-адреса относится к сети, а какая — к хосту. 255.255.255.0 = /24
Шлюз IP-адрес устройства (обычно роутера), через которое компьютер выходит в другие сети. 192.168.1.1
DNS Domain Name System — система, преобразующая понятные имена в IP-адреса. google.com → 142.250.74.14

Как посмотреть свои параметры

Windows: ipconfig /all
macOS: ifconfig или ipconfig getifaddr en0
Linux: ip addr или ifconfig -a

Диапазоны частных адресов

  • 10.0.0.0/8 — крупные корпоративные сети
  • 172.16.0.0/12 — средние сети
  • 192.168.0.0/16 — домашние и офисные сети

Маска подсети — подробнее

Маска подсети — это 32-битное число, которое отделяет сетевую часть IP-адреса от хостовой. В двоичном виде единицы идут подряд слева, а нули — справа:

IP:    192.168.1.10   → 11000000.10101000.00000001.00001010
Маска: 255.255.255.0  → 11111111.11111111.11111111.00000000
                         └──────── сеть ───────┘└─ хост ─┘
Сеть:                   192.168.1.0
Broadcast:              192.168.1.255
Хосты:                  192.168.1.1 … 192.168.1.254 (254 шт.)

Как считать в уме

  • Количество адресов = 2(32 − префикс)
  • Используемых хостов = 2(32 − префикс) − 2
  • /24 → 256 адресов → 254 хоста
  • /30 → 4 адреса → 2 хоста

Маска с подстановочным знаком (Wildcard)

Используется в ACL и OSPF на Cisco. Это инверсия обычной маски.

Формула: wildcard = 255.255.255.255 − маска
Пример: 255.255.255.0 → 0.0.0.255

Полная таблица CIDR

Полная таблица со всеми префиксами от /0 до /32 — в отдельном окне, чтобы не растягивать страницу.

ЗаписьСетьПервыйПоследнийBroadcast
192.168.1.10/24192.168.1.0192.168.1.1192.168.1.254192.168.1.255
10.0.0.5/3010.0.0.410.0.0.510.0.0.610.0.0.7

Диагностика сети

Основные команды для проверки соединения и поиска проблем.

Ping — проверка доступности

Windows: ping 8.8.8.8
macOS / Linux: ping 8.8.8.8 (остановить Ctrl+C)

Traceroute / Tracert

Windows: tracert google.com
macOS / Linux: traceroute google.com

NSLookup / Dig — DNS

Все ОС: nslookup google.com
macOS / Linux: dig google.com

Netstat / SS — соединения и порты

Windows: netstat -an
macOS / Linux: netstat -tuln или ss -tuln

Проверка конкретного порта

Windows (PowerShell): Test-NetConnection google.com -Port 443
macOS / Linux: nc -zv google.com 443

Сброс сетевых настроек

Windows: ipconfig /flushdns, ipconfig /release + ipconfig /renew
macOS: sudo dscacheutil -flushcache
Linux: sudo systemctl restart NetworkManager
Если ping 8.8.8.8 работает, а сайты не открываются — проблема почти наверняка в DNS.

HTTP vs HTTPS

Определения

HTTP — протокол передачи гипертекста, данные передаются в открытом виде.

HTTPS — тот же HTTP, но поверх шифрования TLS/SSL.

Ключевые отличия

ПараметрHTTPHTTPS
Порт по умолчанию80443
ШифрованиеНетДа, TLS/SSL
Защита от перехватаУязвимЗащищён
Аутентификация сервераНетДа, через сертификат
Целостность данныхНе гарантируетсяКонтролируется
Современный статусУстаревшийСтандарт

Что даёт HTTPS

  • Шифрование — данные не видны провайдеру и злоумышленнику.
  • Аутентификацию — сертификат подтверждает, что вы на настоящем сайте.
  • Целостность — данные нельзя подменить по пути.

Проверка сертификата

Все ОС: curl -v https://example.com
OpenSSL: openssl s_client -connect example.com:443 -servername example.com

Серверы

Что такое сервер

Сервер — компьютер или программа, предоставляющая ресурсы и сервисы клиентам по сети. Клиент отправляет запрос — сервер обрабатывает и возвращает ответ.

Типы: веб-сервер (Nginx, Apache), файловый (SMB, FTP), почтовый, БД (MySQL, PostgreSQL), DNS и т.д.

Основные порты

СервисПортНазначение
HTTP80Веб без шифрования
HTTPS443Веб с шифрованием
SSH22Управление Linux
RDP3389Удалённый рабочий стол Windows
MySQL3306База данных MySQL
PostgreSQL5432База данных PostgreSQL
DNS53Разрешение имён
SMB445Сетевые папки Windows

Как подключиться

Linux / macOS: ssh user@server_ip
Windows: ssh user@server_ip (PowerShell 10+) или PuTTY

Для Windows-серверов — mstsc (RDP) или Microsoft Remote Desktop на macOS.

Проверка доступности

Пинг: ping server_ip
Порт (macOS / Linux): nc -zv server_ip 443
Порт (Windows): Test-NetConnection server_ip -Port 443
HTTP: curl -I https://server_ip

Просмотр портов на сервере

Linux: ss -tuln / netstat -tuln
Windows: netstat -an

Базовые принципы

  • Не работайте под root постоянно — используйте sudo.
  • SSH-ключи безопаснее паролей: ssh-keygen → ssh-copy-id.
  • Обновляйте систему: sudo apt update && sudo apt upgrade (Debian/Ubuntu) или sudo dnf upgrade (RHEL/Fedora).
  • Проверяйте логи: journalctl -xe, tail -f /var/log/syslog.
  • Windows — Event Viewer и Get-EventLog в PowerShell.

Маршрутизатор

Что такое маршрутизатор

Маршрутизатор — устройство, которое соединяет разные сети и направляет пакеты на основе таблицы маршрутизации. Домашний роутер = маршрутизатор + коммутатор + точка Wi-Fi.

Основные команды (Cisco IOS)

Режим конфигурацииconfigure terminal

Сохранить конфигcopy running-config startup-config
Интерфейсыshow ip interface brief
VLANshow vlan brief

Порты и интерфейсы

Cisco: show interfaces status, show ip interface brief
MikroTik: /interface print, /ip address print
Linux: ip link show, ip addr, ss -tuln
Windows (RRAS): Get-NetAdapter, Get-NetIPAddress

Настройка VLAN (Cisco)

vlan 10
 name Office
 exit

interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10

show vlan brief
show interfaces status

Транк (несколько VLAN)

interface GigabitEthernet0/1

 switchport trunk allowed vlan 10,20,30

MikroTik: VLAN через bridge

/interface bridge vlan
add bridge=bridge1 tagged=ether1 untagged=ether2 vlan-ids=10

/interface bridge port
set [find interface=ether2] pvid=10

Linux: VLAN через iproute2

sudo ip link add link eth0 name eth0.10 type vlan id 10
sudo ip addr add 192.168.10.1/24 dev eth0.10
sudo ip link set eth0.10 up
Команды VLAN зависят от производителя. Примеры — для Cisco IOS, MikroTik RouterOS и Linux. На домашних роутерах VLAN обычно настраивается через веб-интерфейс.

IP-телефония (VoIP)

IP-телефония — передача голоса по сетям с протоколом IP. В отличие от PSTN, где на звонок выделяется отдельный канал, здесь голос оцифровывается, разбивается на пакеты и передаётся по общей сети.

Как это работает

  1. Регистрация: телефон/софтфон отправляет REGISTER SIP-серверу, тот отвечает 200 OK.
  2. Установка соединения: клиент отправляет INVITE, сервер соединяет абонентов.
  3. Передача голоса: по протоколу RTP в UDP-пакетах.

Ключевые протоколы

ПротоколНазначениеПорт
SIPСигнализация: установка/завершение звонкаUDP/TCP 5060, TLS 5061
RTPПередача голоса и видеоUDP 16384–32768

SIP-методы

МетодНазначение
REGISTERРегистрация абонента на сервере
INVITEИнициирование вызова
ACKПодтверждение ответа на INVITE
BYEЗавершение сессии
OPTIONSПроверка доступности (SIP-ping)
CANCELОтмена несостоявшегося вызова

Диагностика SIP с компьютера

Утилита sipsak отправляет запрос OPTIONS и показывает ответ сервера.

Linux: sudo apt install sipsak
macOS: brew install sipsak
Windows: через WSL, как для Linux

Пример

sipsak -v -s sip:sip.example.com

Успех — SIP/2.0 200 OK или 200 Keepalive.

Если ответа нет

  • Порт 5060/UDP не блокируется файрволом.
  • Правильное имя SIP-сервера.
  • Проблемы с NAT.

IP-телефония на Cisco

Для VoIP используются dial-peer — правила обработки вызовов.

enable
configure terminal

dial-peer voice 10 voip
 description To-SIP-Provider
 destination-pattern 9T
 session protocol sipv2
 session target ipv4:203.0.113.50
 codec g711ulaw
 exit

Параметры:

  • destination-pattern 9T — номер с префиксом 9 (выход на внешнюю линию).
  • session target — IP SIP-провайдера.
  • codec g711ulaw — кодек G.711 (~64 Кбит/с); G.729 — сжатие (~8 Кбит/с).

Особенности через NAT

Если УАТС за NAT, голос может не проходить в одну или обе стороны, хотя вызовы «звонят». SIP в заголовках передаёт внутренние IP, недостижимые снаружи.

  • Включите поддержку NAT в УАТС (Asterisk/FreePBX).
  • Пробросьте на роутере порты SIP (5060) и RTP (10000–20000 или 16384–32768) на внутренний IP УАТС.
  • При смене IP от провайдера обновите его в настройках УАТС.
SIP чувствителен к задержкам и потерям пакетов. Для качественной связи используйте QoS — приоритизацию трафика RTP на маршрутизаторе.

Команды Windows (PowerShell и CMD)

Основные команды для повседневной работы с Windows: установка программ, удалённое управление, работа с процессами, службами, сетью и файлами.

Установка программ (WinGet)

WinGet — официальный пакетный менеджер Microsoft, встроенный в Windows 11 и современные версии Windows 10 (1809+). Позволяет устанавливать, обновлять и удалять приложения из командной строки.

ЗадачаКоманда
Поиск программыwinget search <название>
Установка программыwinget install <PackageId>
Установка по точному IDwinget install --id <PackageId> -e
Тихая установкаwinget install <PackageId> --silent
Обновление всех программwinget upgrade --all
Удаление программыwinget remove <PackageId>
Список установленныхwinget list

Примеры

:: Поиск и установка VLC
winget search vlc
winget install VideoLAN.VLC

:: Установка нескольких программ одной командой
winget install --id Google.Chrome --id Mozilla.Firefox --id VideoLAN.VLC -e

:: Обновление всего установленного ПО
winget upgrade --all
Для установки программ, требующих прав администратора, запускайте PowerShell или CMD от имени администратора. В Windows 11 также можно использовать sudo.

Создать батник

Напишите текст того, что должен делать .bat-файл, и нажмите «Скачать .bat». Файл будет сохранён на ваш компьютер.

Расширение .bat добавится автоматически. Без пробелов и спецсимволов — лучше латиницей.

Если в батнике кириллица и при запуске видны «кракозябры» — попробуйте Windows-1251. UTF-8 обычно работает в Windows 10/11.

Каждая строка — отдельная команда CMD. @echo off отключает вывод команд, pause оставляет окно открытым.
